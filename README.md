# قراء السودان

تطبيق ويب عربي لقراءة القرآن الكريم واستكشاف أصوات القراء السودانيين. مبني باستخدام React وVite.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## الوظائف الحالية

- فهرس السور مع البحث والتصفية.
- قراءة الآيات بواجهة عربية مريحة.
- اختيار القارئ السوداني من قائمة القراء.
- حفظ الآيات في المحفوظات باستخدام `localStorage`.
- مظهر ليلي ونهاري.
- تصميم متجاوب للهاتف والكمبيوتر.
- مشغل صوتي قابل لربط ملفات الصوت المرخصة.

> وضعت روابط الصوت فارغة في البيانات عمداً حتى لا يتم نشر ملفات صوتية دون التحقق من مصدرها وترخيص استخدامها. أضف رابطاً موثقاً في `src/data.js` داخل `audioUrl` لكل قارئ قبل تفعيل التشغيل.

## ملاحظات مهمة

النصوص الموجودة في النسخة التجريبية تغطي بعض السور فقط بهدف العرض. للإطلاق العام، اربط التطبيق بمصدر موثوق للنص القرآني والصوتيات، وراجع أسماء القراء والحقوق قبل النشر.
